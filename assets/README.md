# Assets Folder

This folder contains static assets for the portfolio website.

## images/
Place your personal images here:
- Profile photo for the hero section
- About section photo
- Project screenshots
- Any other images needed

Recommended formats:
- JPG/PNG for photos
- WebP for better compression
- SVG for icons and graphics

## icons/
This portfolio uses inline SVGs in the HTML, so this folder is optional.
You can store custom SVG icons here if needed.

## Image Size Recommendations
- Profile photo: 400x400px (square)
- Project thumbnails: 800x600px or 1200x800px
- Certificate images: 600x400px

## Optimization
- Compress images before adding
- Use WebP format for better performance
- Consider lazy loading for large images
